# 🪙 CryptoApp

¡Bienvenido a **CryptoApp**! Tu puerta de entrada al mundo de las criptomonedas. Este proyecto es un sitio web maquetado que simula una plataforma segura y confiable para el intercambio y gestión de activos digitales. 🚀

## 📖 Descripción

CryptoApp es una aplicación web diseñada para ofrecer una experiencia de usuario fluida y moderna. El sitio destaca las ventajas de utilizar la plataforma, priorizando la seguridad, la facilidad de uso y el soporte al usuario.

## 🛠️ Tecnologías Utilizadas

*   HTML5 🧱
*   CSS3 🎨
*   Bootstrap 5.3.8 🅱️

## 🧪 Pasos para probar este repositorio

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/rollingcodeschool/crypto-app-c22.git
    ```
2.  **Ejecutar el proyecto:**
    Abre el archivo `index.html` en tu navegador web favorito o utiliza una extensión como "Live Server" en VS Code.
